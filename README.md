# Al Samria website design demo

Responsive Arabic website preview for owner review.

- Home, clinic, doctor, offer, booking and confirmation pages.
- Mobile and desktop layouts with working navigation and carousels.
- Doctor photographs open their matching profile pages.
- Appointment forms are demonstrations; no request is delivered to the medical center.
- Sample reviews, experience figures, offer prices and qualifications require verification before production use.

This preview is separate from the live WordPress website and retains noindex instructions.
